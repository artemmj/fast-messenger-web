# Быстромессенджер

Тёмный веб-клиент мессенджера на Vue 3: вход по телефону, профиль, личные и групповые чаты, история переписки и обмен текстовыми сообщениями. Основные экраны доступны на десктопе и мобильных устройствах. Клиент работает с отдельным backend API, адрес которого задаётся через `VITE_API_BASE_URL`.

> Репозиторий содержит только frontend. Возможности сервера и точные правила API следует сверять с backend-контрактом; наличие клиентского вызова само по себе не подтверждает реализацию на сервере.

## Возможности

- Регистрация и вход по телефону и паролю, сохранение сессии и восстановление пользователя.
- Защищённые маршруты и выход из аккаунта.
- Список личных и групповых чатов, название собеседника/группы и информация об участниках.
- Загрузка последней страницы истории сообщений (до 50 сообщений) и оптимистическое отображение отправки текста.
- Получение WebSocket-событий `new_message` и `chat_signal`: первое добавляет сообщение в историю, второе обновляет превью чата и локальный счётчик непрочитанных.
- Профиль пользователя с просмотром данных и изменением email и пароля.
- Адаптивная тёмная раскладка: на небольшом экране список, чат и профиль показываются по одному; из переписки и профиля можно вернуться к списку.

## Архитектура

```text
Vue Router
└── MainLayout
    ├── ChatList ─────────────── chats store
    ├── ChatView ─────────────── messages store
    └── ProfileView ──────────── auth store

Views / components → Pinia stores → src/api (Axios) → backend HTTP API
                                   MainLayout ← WebSocket /ws/chats
```

- **Интерфейс:** Vue 3 Composition API, `<script setup>`, Vue Router; общая тема и адаптивные стили — `src/assets/main.css`.
- **Состояние:** Pinia stores в `src/stores/` отвечают за авторизацию, список чатов, историю сообщений и уведомления.
- **HTTP:** `src/api/` содержит методы auth/users/chats и общий Axios-клиент с bearer-токеном и таймаутом.
- **Realtime:** текущий подключённый WebSocket находится в `src/layouts/MainLayout.vue`. Отправка сообщения выполняется через HTTP `POST`; сокет доставляет серверные события.

Подробнее о потоках данных, известных ограничениях и рекомендуемом порядке работы — в [AGENTS.md](AGENTS.md).

## Запуск

Требуется Node.js `^22.18.0` или `>=24.12.0`.

```sh
npm install
cp .env.example .env
# При необходимости задайте адрес API в VITE_API_BASE_URL
npm run dev
```

Пример `.env.example` использует `http://localhost:8000`. Для production-сборки выполните `npm run build`, для локального просмотра сборки — `npm run preview`.

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Локальный сервер разработки |
| `npm run build` | Production-сборка |
| `npm run preview` | Просмотр production-сборки |

Отдельные команды тестирования и линтинга пока не настроены.
